How a simple grid changed the way we read online

By Staff Writer · 6 min read

Long before screens, printers arranged columns of text on a grid so that readers always knew where to look next. The web has finally caught up.

For years, web pages were built from tables and floats, tools that were never meant for page layout. Designers worked around their limits with clever tricks, and readers often paid the price in cramped columns and awkward gaps.

Modern CSS Grid changed that. A designer can now describe a page as named regions, such as a header, a navigation bar, a main story and a sidebar, and let the browser place everything exactly where it belongs.

One layout, many screens

The same set of named areas can be rearranged for a small phone screen with only a few lines of code. The story moves to the top, the sidebar slides underneath, and nothing needs to be rewritten.

The result is pages that feel closer to a printed magazine: a clear hierarchy, generous white space, and a reading column that is easy on the eyes.
